# Editorial Grid Design System

세이지 그레이 페이지 위에 오프화이트와 블랙 카드를 번갈아 얹고, 얇은 영문 디스플레이 · 마침표가 붙은 거대한 번호 · 가는 대각 화살표 · 흑백 사진으로 구성하는 에디토리얼 덱 스타일입니다. 색을 쓰지 않고 **크기 대비 · 명도 · 헤어라인**으로 위계를 만듭니다.

## 0. 작업 순서 (반드시 이 순서)

1. 포맷을 고르고, 템플릿 HTML과 `assets/editorial.css`를 **같은 결과물 폴더**에 복사한 뒤 `<link href="../assets/editorial.css">`를 `href="editorial.css"`로 바꾼다.
   - 슬라이드 덱(16:9, 1280×720): `templates/deck.html`
   - 세로 롱페이지(웹뷰 · 한 장 PDF · 모바일 공유): `templates/doc.html`
2. 내용을 슬라이드/섹션 단위로 나눈다. **1장 1메시지**로, §5 아키타입 중 하나에 배정한다. 파트가 3개 이상이면 Contents와 Divider를 넣는다.
3. 템플릿 블록을 복제해 텍스트와 사진만 바꾼다. 새 레이아웃을 즉흥으로 만들기 전에 기존 아키타입을 먼저 쓴다.
4. 사진이 있으면 §4 "사진 자리"의 방법으로 교체한다. 없으면 `.ph` 대체 패턴을 그대로 두되, 최종본에서는 `data-ph` 라벨을 남길지 사용자에게 맞춘다(시안이면 남기고, 배포본이면 실제 사진으로 교체).
5. `python3 scripts/render.py <file.html> [out_dir]`로 렌더한다.
6. **반드시 PNG를 열어서 직접 본다.** 덱은 `_check_<name>/sheet.png`와 개별 `sNN.png`, 문서는 `full.png`. §9 체크리스트로 검수하고, 넘침 · 겹침 · 줄바꿈 깨짐을 고친 뒤 다시 렌더한다.

## 1. 원칙 5가지

1. **카드 구조.** 모든 내용은 `--page`(#AEB3AD 세이지 그레이) 위 라운드 카드(`.c.l` 오프화이트 / `.c.k` 블랙) 안에 둔다. 덱 카드는 inset 20px · radius 26, 문서 카드는 간격 14px · radius 24. 카드 안에 또 다른 박스 카드를 만들지 않는다. 나눔은 헤어라인과 여백으로 한다.
2. **유채색 0.** 팔레트는 무채색과 세이지뿐이다. 강조는 ① 검정(막대 1개, 굵은 구절 하나) ② 크기(거대한 번호) 두 가지로만 한다.
3. **얇은 디스플레이 + 거대한 번호.** 큰 제목은 영문 1~2단어(`.disp`, Hanken Grotesk 400, 자간 -0.045em, 행간 0.9). 파트 번호는 마침표까지 붙인 `02.`(`.n`)를 180~300px로 카드 모서리에 크게 둔다. 블랙 카드에서는 흰색, 오른쪽 끝이 살짝 잘려도 된다.
4. **사진은 흑백 블록.** 사진은 카드 가장자리에 붙는 띠(표지 상단 · 마무리 하단)나 콜라주(구분장 좌측), 3열 하단 띠로만 쓴다. 전부 grayscale, 사진 사이 간격은 0(띠·콜라주) 또는 10px(스택).
5. **가는 대각 화살표가 리듬.** ↗는 번호 옆 · 행 끝 · 구분장 좌하단, ↙는 라이트 카드 우상단 코너, ↖는 표지 우하단에 둔다. 굵기 1.5px, 아이콘 칩(배경) 없음.

## 2. 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--page` | #AEB3AD | 바탕(카드 사이) — 유일한 색 기운 |
| `--card` | #F4F4F2 | 오프화이트 카드, 사진 위 흰 탭 |
| `--black` | #0A0A0A | 블랙 카드 |
| `--paper` | #E9E9E6 | 카드 안 한 단계 어두운 면(드물게) |
| `--ink` / `--sub` / `--mute` | #0B0B0B / #6E706C / #A3A5A1 | 본문 / 보조 / 비활성 |
| `--hair` / `--hairD` | rgba(0,0,0,.14) / rgba(255,255,255,.18) | 1px 헤어라인 · 세로 구분선 |
| `--bar` / `--bar2` | #0B0B0B / #B8BCB6 | 막대 강조(1개) / 막대 기본 |
| `--g1`~`--g5` | #D9D9D6 · #B4B5B1 · #8A8B88 · #4A4B49 · #1C1C1C | 사진 대체 패턴용 회색 |

**이 팔레트 외의 색은 쓰지 않는다.** 브랜드 색이 꼭 필요하면 `--page` 하나만 브랜드 계열의 채도 낮은 회색조로 바꾸고(예: 웜그레이 #B5B0A8, 블루그레이 #A9B0B6), 카드 · 텍스트 · 막대는 그대로 둔다.

## 3. 타이포 스케일

폰트는 **Pretendard**(한글 · 본문)와 **Hanken Grotesk**(영문 디스플레이 · 번호 · 라벨) 두 가지다. Hanken Grotesk는 레퍼런스의 상용 네오 그로테스크(Neue Haas · Helvetica Now Display 계열)를 대신하는 무료 Google Font다. `<head>`에 두 링크를 반드시 넣는다(템플릿 참고). 한글은 `word-break:keep-all`.

| 역할 | 덱(1280) | 문서(900) | 클래스 |
|---|---|---|---|
| 표지 · 마무리 디스플레이 | 150–172px / 400 | 112–128px | `.disp` |
| 섹션 디스플레이(Contents 등) | 96–112px | 64–80px | `.disp` |
| 파트 번호 `02.` | 250–300px / 400 | 180–190px | `.n` |
| 열 번호 `01.` | 44–54px | 44px | `.n` |
| 대문자 섹션 제목 | 46–50px / 400 / -0.02em | 40px | `.up` |
| 영문 장 제목 | 30–34px / 400 | 30px | `.t` |
| 한글 헤드라인 | 34px / 500 (강조 구절만 `<b>` 600) | 26px | `.h` |
| 한글 소제목 | 18–21px / 600 | 17–20px | `.ko` |
| 본문 · 서브 | 15px | 14.5px | `.sub` |
| 캡션 · 열 본문 | 12.5–13.5px | 12.5–13px | `.cap` |
| 라벨 · 푸터 | 11px / 400–500 | 11px | `.lbl` `.micro` |

디스플레이는 400(또는 `.disp.lt` 300)만 쓴다. 500 이상 굵은 영문 디스플레이, 이탤릭, 밑줄은 쓰지 않는다. 한글은 600을 넘기지 않는다.

## 4. 컴포넌트

- **마크 `.mark`**: 로고 대신 ✱(8갈래 선) + 대문자 워드마크 `BRAND`. 블랙 카드 우상단, 표지 사진 위 흰 탭, 푸터 좌측에 쓴다. 실제 로고는 사용자가 요청할 때만 넣는다.
- **흰 탭 `.tab`**: 사진 띠의 아래 경계에 붙는 오프화이트 반탭(위 모서리만 둥글게). 표지에서 마크를 담는다. `top` = 사진 높이 − 38px.
- **필 `.pill`**: 1px 아웃라인 캡슐. `Part 2`, `3 Parts` 같은 메타만. `.sm`은 헤더용, `.fill`은 한 줄에 하나만.
- **화살표 `.arr`**: `assets/icons.md`. `.sm` 18px(행 끝 · 코너) / 기본 30px(번호 옆) / `.lg` 44px(표지 · 마무리).
- **헤어라인 행 `.rows`**: 목차 · 스펙 · 연락처 · 분기표. 자식 div마다 `grid-template-columns`를 직접 지정한다. 행 끝에 ↗ 하나.
- **세로 구분 열 `.cols`**: 3열(서비스 · 원칙) 또는 4열(분기 로드맵). 열 사이에 1px 세로선, 열 안은 `번호 → 영문 라벨 → 한글 소제목 → 캡션 → 하단 사진 띠` 순서. 박스로 감싸지 않는다.
- **막대 그래프 `.chart`**: `.b`(세이지) 여러 개 + `.b.on`(검정) 1개. 값 라벨은 `<span>`으로 막대 위. x축은 `.chart-x`. 25% 간격 헤어라인 그리드와 아래 1px 검정 기준선이 자동으로 깔린다. 차트 라이브러리는 쓰지 않는다. 가로 비율 막대가 필요하면 `.hbar`.
- **푸터 `.ft`**: 좌측 `✱ 섹션명`(Introduction & Business Overview 같은 영문), 우측 `Confidential   P.NN`(번호만 ink · 600). 표지와 구분장에는 푸터를 두지 않는다.
- **헤더 `.hd`**: 좌측 마크 또는 `NN. 섹션명`(micro) 또는 영문 장 제목(`.t`), 우측 ↙ 코너 화살표. 블랙 카드는 좌측 Part 필, 우측 마크.

### 사진 자리 `.ph`

레퍼런스의 흑백 사진은 CSS 패턴으로 대체해 두었다. 모두 `data-ph="이미지 자리 · 건축"`처럼 라벨이 붙어 시안임이 보인다.

| 클래스 | 그림 | 어울리는 자리 |
|---|---|---|
| `.ph.arch` | 하늘 + 건축 매스 | 구분장 콜라주 상단, 케이스 큰 사진 |
| `.ph.facade` | 사선 루버 | 3열 하단 띠, 마무리 띠 |
| `.ph.grid` | 격자 창 | 3열 하단 띠 |
| `.ph.slat` | 수평 슬랫 | 3열 하단 띠 |
| `.ph.tone` | 부드러운 회색 그라데이션 | 인물 · 실내 자리 |
| `.ph.arc` | 어두운 벽 + 흰 원호 | 콜라주 작은 칸 |
| `.ph.window` | 어두운 실내 + 밝은 창 | 표지 띠, 스택 |
| `.ph.desk` | 탑뷰 테이블 · 사물 | 표지 띠, 스택 |

**실제 사진으로 바꾸는 법**
1. 같은 요소에 `style="background-image:url(photo.jpg)"`를 넣고 `data-ph` 속성을 지운다(패턴 클래스는 지워도 되고 둬도 된다 — 인라인 이미지가 우선).
2. `.ph`가 `filter:grayscale(1) contrast(1.05)`와 `background-size:cover; background-position:center`를 이미 처리한다. 피사체가 잘리면 `background-position:30% 40%`처럼 초점을 옮긴다.
3. 원본이 탁하면 `filter:grayscale(1) contrast(1.15) brightness(1.03)`까지 올린다. 컬러 사진을 그대로 쓰지 않는다.
4. 크롭 기준: 표지 띠는 가로 3장(비율 1 : 1.3 : 0.85), 3열 하단 띠는 건축 디테일 · 질감 클로즈업, 구분장 콜라주는 큰 건축 1 + 풍경 1 + 작은 면 2. 인물은 띠의 양 끝에만 둔다.
5. 사진 위에는 텍스트를 올리지 않는다(흰 탭만 예외).

## 5. 아키타입 (템플릿에 전부 있음)

**덱 `templates/deck.html`** — 톤 순서 L L K L L L K L
1. **Cover**(라이트): 상단 318px 사진 띠 3장 + 흰 탭 마크. 좌하단 디스플레이 2줄(160px), 가운데 한글 제목 + 캡션, 우측 `YE/AR 2026` · URL, 우하단 ↖ lg.
2. **Contents**(라이트): 좌측 `Contents` 104px + 필 2개 + 서브. 우측 `.rows` 목차(`01.` 52px / 영문 라벨 + 한글 제목 / 캡션 / `P.03` / ↗).
3. **Divider**(블랙 · 분할): 좌측 560px 흑백 콜라주, 우측 블랙에 `Part 2` 필 · 마크 · 대문자 제목 · 서브, 우하단 `02.` 250px, 좌하단 ↗.
4. **Offerings**(라이트): 상단 `.t` 장 제목 + ↙. 세로 헤어라인 3열, 각 열 `↗ 01.` → 라벨 → 한글 소제목 → 캡션 → 하단 180px 사진 띠.
5. **Data**(라이트): 좌측 `.t` + `.h`(강조 구절 하나) + 서브 + 하단 대형 수치(`2.4x` 96px). 우측 막대 그래프(세이지 + 검정 1개) + 범례.
6. **Case Study**(라이트): 좌측 텍스트 + 하단 스펙 행. 우측 세로 큰 사진 1 + 3단 스택 사진.
7. **Roadmap**(블랙): 대문자 제목, 우상단 잘린 `03.` 300px, 하단 4열(Q1–Q4) 세로 헤어라인.
8. **Closing**(라이트): `Thank you.` 150px, 우측 연락 행(↗), 하단 236px 사진 띠 3장.

**문서 `templates/doc.html`**: Hero(라이트, 사진 띠 + 탭 + 디스플레이 + 연도 줄) → Offerings(라이트, 3열) → Divider(블랙 분할, `02.`) → Data(라이트, 수치 + 막대) → Roadmap(블랙, 분기 행 + 잘린 `03.`) → Closing(라이트, Thank you + 연락 + 사진 띠).

## 6. 레이아웃 규칙

- **덱 좌표계**: 카드는 1240×680(inset 20). 카드 안 콘텐츠는 left/right 52px, top 110~136px, bottom 70~78px. 헤더 top 40~46px, 푸터 bottom 26px. 복잡한 장은 `position:absolute`로 블록을 고정 배치한다(템플릿 방식).
- **블리드**: 사진 띠와 콜라주는 카드 가장자리에 여백 없이 붙인다(카드 radius가 모서리를 자른다). 텍스트 영역에만 52px 여백.
- **분할**: 좌측 380~520px 텍스트 열 + 우측 가변. 블랙 분할은 사진 560 : 블랙 680. 같은 폭 열은 `.cols` 3열 · 4열에만 허용한다.
- **간격**: 사진 스택 10px, 열 안 요소 6~16px, 블록 사이 22~40px, 3열 좌우 padding 28px.
- **정렬**: 전부 좌측 정렬. 거대한 번호만 우측 정렬. 가운데 정렬은 쓰지 않는다.
- **줄바꿈은 직접 정한다**: 제목 · 캡션은 `<br>`로 의미 단위에서 끊는다. 날짜 · 수치 · 영문 라벨은 `white-space:nowrap`.

## 7. 카피 규칙

- 영문은 디스플레이 · 대문자 제목 · 라벨 · 푸터에만(`Brand Plan`, `RESEARCH & ANALYSIS`, `Service Offerings`, `Confidential P.04`). 의미는 한글 헤드라인과 본문이 전달한다.
- 한글 헤드라인은 사실을 단정형으로 쓰고, **한 구절만** `<b>`로 강조한다. 예: "3년 사이 시장이 **두 배 넘게** 커졌습니다".
- 열 캡션은 2줄 이내, 한 줄 18~22자 안팎.
- 번호는 항상 `01.` `02.`처럼 두 자리 + 마침표. 페이지는 `P.05`.
- 근거 없는 최상급("국내 유일", "업계 최고")은 쓰지 않는다. 가상 수치는 캡션에 "(가상 수치)"로 밝힌다.

## 8. 금지 사항 (생성형 티가 나는 것)

- 컬러 사진, 이모지, 컬러 · 채운 아이콘, 원형 · 사각 아이콘 칩, 3D 일러스트
- 유채색 액센트, 다색 차트, 배경 그라데이션, 글로우, `box-shadow`, 글래스모피즘
- 카드 안 카드, 3열을 각각 박스로 감싸기, 굵은 테두리, 표 격자 · 지브라

## 10. 확장

- **새 아키타입**: 기존 블록을 조합한다. 예: Divider의 좌측 콜라주 + Offerings 3열 / 블랙 전면 카드 + 좌측 아래로 잘린 `04.` + 대문자 제목(파트 표지 B형) / Case Study의 스택 사진을 4장 그리드로.
- **목업**: 화면 시안은 사진 자리 안에 흰 브라우저 프레임(회색 바 + 본문 회색 막대)을 HTML로 그린다. 컬러 스크린샷은 grayscale 필터를 건다.
- **여러 문서 일관성**: 데이터(dict/JSON) + 템플릿 함수로 생성기를 만들면 장수가 많아도 톤이 흔들리지 않는다.
