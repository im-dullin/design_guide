# 아이콘 세트 (24×24 선 아이콘)

이 디자인의 아이콘은 **대각 화살표 4종과 ✱ 마크**가 전부입니다. 모두 `viewBox="0 0 24 24"`, `fill:none`, `stroke:currentColor`이고, 화살표는 굵기 1.5px에 끝을 각지게(`square`) 처리합니다. 스타일은 `editorial.css`의 `.arr`, `.mark`가 맡습니다. 원형·사각 아이콘 칩(배경)은 쓰지 않습니다.

```html
<span class="arr"><svg viewBox="0 0 24 24"><path d="M5 19L19 5M8 5h11v11"/></svg></span>        <!-- 30px 기본 -->
<span class="arr sm">…</span>   <!-- 18px · 목차 행 끝, 카드 우상단 -->
<span class="arr lg">…</span>   <!-- 44px · 표지 · 마무리 우하단 -->
<span class="mark"><svg viewBox="0 0 24 24"><path d="M12 3v18M3 12h18M5.6 5.6l12.8 12.8M18.4 5.6L5.6 18.4"/></svg>BRAND</span>
```

| key | 모양 | 용도 | path |
|---|---|---|---|
| ne | ↗ | 번호 옆, 목차·연락 행 끝, 구분장 좌하단 (기본) | `<path d="M5 19L19 5M8 5h11v11"/>` |
| sw | ↙ | 라이트 카드 우상단 코너 표식 | `<path d="M19 5L5 19M5 8v11h11"/>` |
| nw | ↖ | 표지 우하단(큰 사이즈) | `<path d="M19 19L5 5M5 16V5h11"/>` |
| se | ↘ | 다음 장으로 이어짐 | `<path d="M5 5l14 14M19 8v11H8"/>` |
| mark | ✱ | 로고 대신 쓰는 8갈래 마크 (굵기 2.2, round) | `<path d="M12 3v18M3 12h18M5.6 5.6l12.8 12.8M18.4 5.6L5.6 18.4"/>` |

규칙
- 한 카드에 화살표는 **같은 방향 반복** 또는 코너 표식 1개까지. 방향을 섞어 장식처럼 뿌리지 않는다.
- 세트에 없는 아이콘(사람·차트 등)은 만들지 않는다. 의미는 번호와 라벨로 전달한다.
- 이모지, 컬러 아이콘, 채운 아이콘은 쓰지 않는다.
