# Midnight Aurora Design System

거의 검정인 화면 위에 가는 글자와 한 가지 블루만 두고, 표지에서만 모서리 오로라가 번지는 SaaS 피치덱 스타일입니다. 카드나 장식 대신 **넓은 검정 여백 · 가는 굵기 · 한 구절의 블루**로 고급스러움을 만듭니다.

## 0. 작업 순서 (반드시 이 순서)

1. 포맷을 고르고, 템플릿 HTML과 `assets/midnight-aurora.css`를 **같은 결과물 폴더**에 복사한 뒤 `<link href="../assets/midnight-aurora.css">`를 `href="midnight-aurora.css"`로 바꾼다.
   - 슬라이드 덱(16:9, 1280×720): `templates/deck.html`에서 시작
   - 세로 롱페이지(웹뷰·한 장 PDF·모바일 공유): `templates/doc.html`에서 시작
2. 내용을 먼저 슬라이드/섹션 단위로 나눈다. **1장 1메시지**로, 아래 §5 아키타입 중 하나에 배정한다.
3. 오로라를 쓸 장(표지 · 구분장 · 마무리)을 먼저 정하고, 나머지 장의 그라데이션 종류(하이라이트 열 / 막대 / 없음)를 장마다 하나로 정한다(§2.1).
4. 템플릿 블록을 복제해 텍스트만 바꾼다. 새 레이아웃을 즉흥으로 만들기 전에 기존 아키타입을 먼저 쓴다.
5. `python3 scripts/render.py <file.html> [out_dir]`로 렌더한다.
6. **반드시 PNG를 열어서 직접 본다.** 덱은 `_check_<name>/sheet.png`(전체)와 개별 `sNN.png`, 문서는 `full.png`. PDF도 한 장 열어 오로라가 살아 있는지 확인한다. §9 체크리스트로 검수하고 다시 렌더한다.

## 1. 원칙 5가지

1. **검정이 주인공.** 모든 장의 바탕은 `--night`(#0c0c0d) 하나다. 라이트 장, 회색 패널, 카드 배경은 없다. 구획은 어두운 행 바(`--bar`)와 1px 프레임(`--line`)으로만 한다.
2. **오로라는 정해진 자리에만.** 오로라(`.aurora`)는 표지 · 구분장 · 마무리에만, **한 장에 1개**, 모서리에서 번진다(표지는 우상단, 마무리는 `.aurora.low`로 우하단). 본문 장에는 배경 그라데이션을 넣지 않는다.
3. **블루는 한 계열, 한 구절.** 텍스트 강조는 `.a`(`--ice` #a9cdf5)로 헤드라인 안 **한 구절만** 칠한다. 숫자 하나를 ice로 칠하면 같은 장의 다른 숫자는 흰색으로 둔다.
4. **크게 쓸수록 가늘게.** 영문 디스플레이는 Urbanist 300(초대형 숫자는 200), 한글 헤드라인은 Pretendard 300이다. 굵은 제목으로 위계를 만들지 않고 **크기와 색**으로 만든다.
5. **라벨은 작고 조용하게.** 섹션 이름은 좌상단 12px 회색 영문 라벨(`.lbl`: "Competitors", "Financials") 하나로 끝낸다. 번호 목록은 `(01)` 형식의 작은 회색 번호(`.nl`)를 쓴다.

### 2.1 그라데이션 규칙 (이 4종 외 금지)

| 이름 | 변수 / 클래스 | 어디에 | 크기·형태 | 장당 최대 |
|---|---|---|---|---|
| Aurora | `--g-aurora` · `.aurora` | 표지 · 구분장 | radial 4겹, 중심은 우상단 모서리 바깥(100% 0%), 가장 밝은 층은 가로 52%·세로 70% 타원, 넓은 층은 가로 72%·세로 118%. 좌상단에 옅은 회청색 1겹, 우하단 모서리에 작은 반사 1겹 | 1 |
| Aurora low | `--g-aurora-low` · `.aurora.low` | 마무리(Thank you) | 같은 구성을 우하단(100% 100%) 기준으로 | 1 |
| Column | `--g-col` · `.cmp .hl` | 비교표의 우리 열 | 위 34% → 아래 16% sky 반투명, radius 14, 테두리 1px ice 22% | 1열 |
| Bar | `--g-bar` · `.chart .b` | 막대 차트 | 위 #171c23(밤) → 38% #22324a → 74% #4f7fb5 → 아래 #86b8ee, 상단 radius 16·하단 직각 | 막대 3–5개 |
| Meter | `.meter i` | 가로 진행 막대(보조) | 90deg #2a4060 → `--sky`, 높이 6px | 2개 |

- **한 장에는 한 종류만.** 오로라 장에는 Column·Bar를 두지 않고, 본문 장에서는 Column과 Bar를 같이 쓰지 않는다(Meter는 보조라 예외).
- 오로라 장 사이에는 그라데이션 배경이 없는 본문 장이 최소 3장 있어야 한다. 8장 덱이면 오로라는 표지 + 마무리, 많아야 구분장 1장까지 총 3장이다.
- 오로라는 **글자 뒤 모서리**에만 있다. 헤드라인 바로 뒤를 밝게 덮지 않는다(표지 헤드라인은 좌하단, 오로라는 우상단). 글자는 `z-index:2`로 오로라 위에 둔다.
- `filter:blur()`, `backdrop-filter`, `box-shadow` 글로우, 이미지 오로라는 쓰지 않는다. PDF 인쇄에서 빠지거나 깨진다. 전부 `radial-gradient` / `linear-gradient`로 그린다.
- 보라·핑크·민트 등 다른 색조의 오로라 금지. 블루 한 계열 안에서 명도만 바꾼다.

## 3. 타이포 스케일

폰트는 Urbanist(영문 디스플레이·숫자·라벨)와 Pretendard(한글·본문) 두 가지다. `<head>`에 두 링크를 반드시 넣는다(템플릿 참고). 디스플레이·헤드라인은 `font-family:"Urbanist","Pretendard"`로 지정되어 있어, 한 줄에 영문과 한글이 섞여도 각자 맞는 서체로 나온다. 한글은 `word-break:keep-all`로 어절 단위 줄바꿈을 유지한다.

| 역할 | 덱(1280) | 문서(900) | 클래스 |
|---|---|---|---|
| 표지 디스플레이 (ice) | 84–132px / 300 / -0.03em / 1.02 | 64px | `.disp` |
| Thank you | 120px / 300 | 48px | `.disp` |
| 섹션 디스플레이 (Financials 등) | 52–64px / 300 | 40px | `.disp` |
| 한글 헤드라인 | 42px(문장형 52px) / 300 / -0.035em / 1.24 | 32px | `.h` (강조 `.a`) |
| 초대형 숫자 | 140–180px / 200 | — | `.num` |
| 대형 숫자 | 40–72px / 300 | 34–44px | `.num` |
| 막대 값 | 30–38px / 300 흰색 | 30px | `.chart .v` |
| 리드 | 17px / 300 | 17px | `.lead` |
| 행 제목 | 15px / 400 (목차 22px / 300) | 15–18px | `.t` |
| 본문/서브 | 15px / 300 | 14.5px | `.sub` |

## 4. 컴포넌트

- **섹션 라벨 `.lbl`**: 본문 장 좌상단(`.hd` 왼쪽)에 영문 한두 단어. 우측에는 페이지 번호(`03`)만 둔다. 표지·마무리 좌상단은 워드마크 `.wm`.
- **행 바 `.rbar`**: `--bar` 배경, radius 10, 높이 42, 1px 거의 안 보이는 테두리. 표 행, 입력 바(`--bar2`, 높이 50), 3단계 스텝 박스에 쓴다. 행 바 안에 행 바를 넣지 않는다.
- **프레임 `.frame`**: 1px `--line` 아웃라인, radius 22, 배경 없음. 차트·제품 데모처럼 "한 덩어리"인 것만 감싼다. 장당 1개.
- **비교표 `.cmp`**: 행마다 `.r`(행 바), 첫 행은 `.r.head`(배경 없음, 열 이름 13px). 열 폭은 각 행 `grid-template-columns`에 같은 값(`340px repeat(4,110px) 1fr`)으로 직접 지정한다. 우리 열 위에 `.hl`을 절대 위치로 겹친다(`left`=첫 열 폭, `width`=열 폭). 헤더 위 6px부터 마지막 행 아래 10px까지 덮는다. 지원은 `.ck`, 미지원은 `.nx` 대시. 행은 4–7개.
- **막대 차트 `.chart`**: `.frame` 안에 넣고, 막대 `.b`의 `height`를 %로 준다(최대 92%). 값 `.v`는 막대 안 위쪽, 연도 `.y`는 막대 안 아래쪽. 막대 3–5개, 간격 10–12px. 축·눈금·격자는 그리지 않는다. 단위는 차트 밖 캡션에 적는다.
- **번호 리스트 `.nl`**: `<li data-n="(01)">`로 번호를 붙인다. 위에 `.nl-t`(ice 13.5px 영문 제목: "Growth drivers", "Core features") 한 줄. 항목 3–5개. `.nl.lg`는 목차용 큰 버전.
- **헤어라인 행 `.rows`**: 목차, 지표 리스트, 로드맵, 연락처. 자식 div마다 `grid-template-columns`를 지정한다. 세로선·격자 없음.
- **태그 `.tag`**: 1px 아웃라인 캡슐 + sky 점. 상태·버전 표시에 장당 1개.
- **미터 `.meter`**: 6px 가로 진행 막대. 목표 대비 진행률 등 보조 지표에만.

## 5. 아키타입 (템플릿에 전부 있음)

**덱 `templates/deck.html`**
1. **Cover**: `.aurora`(우상단). 좌상단 워드마크, 우상단 문서 종류 `.lbl`. 좌하단(bottom 150px)에 영문 디스플레이 2줄(ice, 84px) + 한글 리드 한 줄. 푸터에 라운드 · 날짜 / Confidential.
2. **Contents**: 좌측 헤드라인(한 구절 ice) + 서브, 우측(left 560) `.rows` 목차 5행: `(01)` / 제목 22px / 캡션 / 페이지.
3. **Problem**: 상단 문장형 헤드라인 52px(흰색 + ice 한 구절) + 서브. 하단 3열 숫자(첫 숫자만 ice), 각 열 위 헤어라인.
4. **Product**: 좌측 헤드라인 + 하단 `.nl` 기능 3개. 우측 `.frame` 안에 입력 바, 3단계 스텝 박스(마지막 단계만 ice), 하단 지표 + 태그.
5. **Competitors**: 헤드라인 2줄 + 가운데 `.cmp` 비교표, 우리 열 `.hl`. 푸터에 비교 기준 각주.
6. **Traction**: 좌측 헤드라인 + 초대형 숫자 1개(ice, 180px/200). 우측 `.rows` 지표 3행(흰 숫자 52px) + 미터 1개.
7. **Financials**: 좌측 세로 중앙 영문 디스플레이 52px + 단위 서브, 좌하단 `.nl` Growth drivers. 우측 `.frame`(top/right/bottom 48px) 안 막대 3개. 프레임이 헤더 자리를 덮으므로 이 장은 페이지 번호를 생략한다.
8. **Closing**: `.aurora.low`(우하단). 워드마크, "Thank you" 120px(ice), 한 문장, 좌하단 연락처 `.rows` 2행. 푸터 없음.

구분장이 필요하면 Cover 구조를 복제해 디스플레이만 "Part 02 · Go-to-market"처럼 바꾸고 리드 한 줄만 둔다(오로라 장 수 규칙 §2.1 준수).

**문서 `templates/doc.html`**: Hero(오로라, 디스플레이 64px, 지표 3열) → Problem(헤드라인 + 번호 행 3개) → Competitors(비교표) → Financials(좌 300px 디스플레이 · 리스트, 우 프레임 막대) → Roadmap(번호 행 3개, 마지막만 ice) → Contact(Let’s talk + 연락처 행). 섹션은 `.sec`(radius 8, padding 52/56)을 10px 간격으로 쌓는다. 오로라는 Hero 한 곳에만.

## 6. 레이아웃 규칙

- **덱 좌표계**: 좌우 여백 64px, 헤더 top 46px, 본문 top 104px, 푸터 bottom 34px, 본문 bottom 72px. 블록은 `position:absolute`로 고정 배치한다(템플릿 방식).
- **여백을 채우지 않는다.** 검정 빈 공간이 화면의 40% 이상이어도 괜찮다. 대신 요소는 화면 위쪽(헤드라인)과 아래쪽(숫자·리스트)에 붙여 긴장감을 만든다.
- **비대칭 분할**: 좌측 360–480px 텍스트 열 + 우측 프레임(`left:560–640px; right:48–64px`). 똑같은 블록을 4개 이상 균등 나열하지 않는다(비교표 열 제외).
- **헤드라인은 좌측 정렬, 2줄.** 줄바꿈은 `<br>`로 의미 단위에서 직접 끊는다. 가운데 정렬은 쓰지 않는다(비교표 셀만 예외).
- **간격**: 행 바 사이 6px, 리스트 항목 사이 10px, 헤드라인과 서브 18–24px, 블록 사이 40px 이상.
- 짧은 값(연도, 숫자, 분기)에는 `white-space:nowrap`.

## 7. 카피 규칙

- 헤드라인은 **대비 구조**로 쓰고 뒤 구절을 ice로 칠한다. 예: "다른 도구는 검색하고, **우리는 맥락을 이해합니다**", "도입 6개월, 검색 시간이 **절반으로**".
- 영문은 디스플레이(표지 제목, "Annual Recurring Revenue", "Thank you")와 라벨(`Competitors`, `Growth drivers`, `Tool A`)에만 쓴다. 본문·설명·리스트 항목은 한글로 쓴다.
- 리스트 항목과 행 제목은 6–14자 명사형으로 끝낸다("제품 주도 성장", "지식 자동 갱신").
- 숫자를 앞에 세운다("−52%", "4.2h", "81%"). 가상의 수치라면 푸터에 `* 가상의 예시 수치입니다`를 단다.
- 경쟁사는 실명 대신 `Tool A–C`, 비교 기준을 푸터 각주로 밝힌다. 근거 없는 최상급("유일", "최고")은 쓰지 않는다.

## 8. 금지 사항 (생성형 티가 나는 것)

- 본문 장의 배경 그라데이션, 한 장에 오로라 2개, 화면 가운데에 뜬 오로라 구체
- `filter:blur` · 글로우 · 네온 · `box-shadow` · 글래스모피즘(`backdrop-filter`)
- 보라·핑크·민트·주황 등 블루 외 색, 무지개 그라데이션, 그라데이션 텍스트
- 라이트 배경 장, 회색 카드에 내용 채우기, 카드 안의 카드
- 굵은 제목(600+), 이탤릭, 밑줄, 대문자 영문 헤드라인
- 표 격자·세로선·지브라 줄무늬, 차트 축·눈금·격자선
- 이모지, 컬러 아이콘, 3D 일러스트, 스톡 사진, 실제 브랜드 로고
- 길고 설명적인 문장, 불릿 6개 이상, 한 장에 강조 구절 2개 이상

## 9. 검수 체크리스트 (렌더 PNG · PDF를 보면서)

- [ ] 텍스트가 프레임·행 바 밖으로 넘치거나 다른 요소와 겹치지 않는다. 특히 긴 영문 디스플레이, 비교표 마지막 행, 막대 값.
- [ ] 한글이 어절 중간에서 끊기지 않고, 짧은 값(연도·숫자)이 두 줄로 갈라지지 않는다.
- [ ] 오로라는 표지·구분장·마무리에만 있고 장당 1개다. PDF에서도 오로라가 보인다.
- [ ] 본문 장마다 그라데이션 종류가 하나 이하이고, ice 강조 구절이 하나다.
- [ ] 비교표 `.hl`이 우리 열과 정확히 겹친다(헤더~마지막 행).
- [ ] 막대 높이 비율이 값 비율과 대체로 맞고, 가장 큰 막대가 프레임 상단에 붙지 않는다(≤92%).
- [ ] Urbanist가 로드됐다(숫자 1과 영문 a가 기하학 형태인지). 안 보이면 링크·네트워크를 확인한다.
- [ ] 페이지 번호와 목차 번호가 실제와 일치한다. 실제 회사명·로고·개인정보가 의뢰처 의도와 맞다.

## 10. 확장

- **새 아키타입이 필요할 때**: 기존 블록을 조합한다. 예: 좌측 텍스트 열 + 우측 프레임 안 `.rows` 가격표 / 프레임 안 행 바로 만든 팀 소개 / Traction 구조에 미터 3개.
- **목업**: 제품 화면은 스크린샷 대신 프레임 안 입력 바 + 행 바로 간단히 그린다(Product 아키타입 참고).
- **브랜드 색 교체**: `--ice`, `--sky`와 `--g-*` 변수 안의 블루 rgba를 같은 명도의 브랜드 계열로 바꾼다. 따뜻한 색(주황·빨강)은 이 스타일과 맞지 않으므로 권하지 않는다.
- **여러 문서 일관성**: 데이터(dict/JSON)와 템플릿 함수로 생성기를 만들면 문서를 여러 개 만들어도 톤이 흔들리지 않는다.
