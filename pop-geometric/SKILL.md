# Pop Geometric Design System

둥근 기하 대문자를 슬라이드 폭 끝까지 키우고, 남는 자리를 원색 캡슐이 메우는 팝 스튜디오 스타일입니다. 장식은 **글자 · 캡슐 · 원색 면** 세 가지뿐이고, 크기와 색 면적으로 경쾌함을 만듭니다.

## 0. 작업 순서 (반드시 이 순서)

1. 포맷을 고르고 템플릿 HTML과 `assets/pop.css`를 **같은 결과물 폴더**에 복사한 뒤 `<link href="../assets/pop.css">`를 `href="pop.css"`로 바꾼다.
   - 슬라이드 덱(16:9, 1280×720): `templates/deck.html`
   - 세로 롱페이지(웹뷰·한 장 PDF·모바일 공유, 900px): `templates/doc.html`
2. 내용을 장 단위로 나눈다. **1장 1메시지**로, §5 아키타입 중 하나에 배정한다. 배경색 순서를 먼저 정한다(흰 장과 원색 장 교차).
3. 템플릿 블록을 복제해 글자만 바꾼다. 디스플레이 줄은 글자 수가 바뀌면 캡슐이 폭을 알아서 채운다(`.pl`이 flex:1). 글자가 넘치면 font-size를 줄인다.
4. `python3 scripts/render.py <file.html> [out_dir]`로 렌더한다.
5. **반드시 PNG를 열어서 직접 본다.** 덱은 `_check_<name>/sheet.png`와 `sNN.png`, 문서는 `full.png`. §9로 검수하고 넘침·겹침·줄바꿈을 고친 뒤 다시 렌더한다.

## 1. 원칙 5가지

1. **꽉 찬 디스플레이.** 표지·마무리 디스플레이는 좌우 40px 여백까지 꽉 채운다. 줄은 `.ln`(flex)이고 글자 덩어리 `.t` 사이·뒤의 빈 폭은 캡슐 `.pl`이 채운다. 글자를 가운데 작게 두지 않는다.
2. **캡슐 = 글자 높이.** 캡슐은 디스플레이 글자의 캡하이트와 정확히 같은 높이로 맞물린다(`.t`에 `text-box: trim-both cap alphabetic`, `.pl`은 stretch). 캡슐 안은 비워 두거나 연도·워드마크·짧은 라벨 하나만 넣는다.
3. **한 장 한 배경색, 통짜로.** 배경은 흰색·노랑·빨강·코발트·그린 중 하나를 슬라이드 전체에 칠한다(`.bg-w|y|r|b|g`). 패널·카드·그라데이션으로 나누지 않는다. 흰 장과 원색 장을 교차한다.
4. **영문은 기하 대문자, 한글은 주아.** 영문 디스플레이는 Righteous 대문자(2~10자 단어), 한글 헤드라인·문장형 디스플레이는 Jua(둥근 헤비 고딕)로 쓴다. 한글을 Righteous 크기 그대로 대응시키지 않는다 — §3 참고.
5. **작은 푸터가 질서를 잡는다.** 모든 장 하단에 `.ft` 한 줄(설명 2줄 · Page NN · Copyright · 워드마크)을 둔다. 화면이 시끄러워도 이 한 줄이 문서처럼 보이게 한다.

## 2. 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | #ffffff | 흰 장 · 흰 캡슐 |
| `--ink` | #0b0b0b | 글자 · 거대 따옴표 · 검정 캡슐 |
| `--red` | #e04b52 | 캡슐 · 패턴 도형 · 노랑 위 제목 |
| `--yellow` | #f2bd45 | 통짜 배경(Statement·패턴) · 캡슐 |
| `--blue` | #2f4bf0 | 통짜 배경(지표) · 워드마크 캡슐 |
| `--green` | #2f4a33 | 통짜 배경(마무리) · 캡슐 |
| `--mist` | #d4d7df | 문서 바깥 배경(블록 사이 틈) |
| `--sub` | #5f5f5f | 흰 바탕 보조 텍스트 |

**원색은 이 4개뿐이다.** 틴트(연한 노랑 등), 투명도 겹침, 그라데이션은 쓰지 않는다. 배경과 글자 조합: 흰·노랑·빨강 위는 검정 글자(노랑 위 제목은 빨강도 허용), 코발트·그린 위는 흰 글자. 브랜드 색을 넣으려면 네 원색 중 하나만 바꾼다.

## 3. 타이포 스케일

폰트 4종(`<head>`에 템플릿의 두 링크 필수): **Righteous**(영문 디스플레이·숫자·라벨·워드마크) · **Jua**(한글 디스플레이·헤드라인) · **Pretendard**(본문·푸터) · **Noto Serif KR / Instrument Serif**(인용). 한글은 `word-break:keep-all`.

| 역할 | 덱(1280) | 문서(900) | 클래스 |
|---|---|---|---|
| 표지·마무리 디스플레이(3줄 이하) | 212–252px | 150–172px | `.disp` + `.ln` |
| 섹션 디스플레이(1~2줄) | 84–150px | 64–96px | `.disp` (line-height .86–.9) |
| 한글 Statement(양끝 맞춤 4~6줄) | 84–92px / lh 1.02–1.08 | 56–60px | `.kd.just` |
| 한글 헤드라인 | 26–34px | 22–32px | `.kd` / `.h` |
| 큰 숫자 | 96px | 64px | `.num` |
| 인용문 | 33–36px / lh 1.42 | 27px | `.serif-ko` |
| 본문 | 15px / 1.6 | 14–15px | `.sub` |
| 캡션 | 12.5px | 12.5px | `.cap` |
| 라벨 | 12–13px Righteous 대문자 | 동일 | `.lab` |
| 푸터 | 10px Pretendard · 워드마크 17px | 동일 | `.ft` / `.wm` |

**한글 헤드라인 세팅법.** 원본 레퍼런스의 "꽉 찬 영문 대문자 문장"은 한글에서 Jua 양끝 맞춤으로 옮긴다. 줄마다 `<div>`, 어절마다 `<span>`을 두고 `.just`가 어절 사이만 벌린다(글자 사이는 벌리지 않음). 한 줄에 2~5어절, 12~15자 내외로 끊고 줄 길이를 일부러 들쭉날쭉하게 두면 빈 간격이 리듬이 된다. Jua는 굵기가 하나뿐이니 bold·이탤릭을 주지 않는다. 한글 단어를 `.disp`(Righteous)에 넣지 않는다(한글 글리프가 없어 대체 서체로 깨진다).

## 4. 컴포넌트

- **디스플레이 줄 `.ln`**: `<div class="ln"><span class="t">PO</span><span class="pl r">2026</span><span class="t">P</span></div>`. 부모 `.disp`에 font-size를 준다. 줄 간격은 `.17em`으로 고정. 한 줄에 캡슐 1~2개, 한 화면에 3~4색까지.
- **캡슐 `.pl`**: `.r .y .b .g .k .w` 색. 기본은 남는 폭을 채우고(flex:1), 폭을 고정하려면 `.fix` + `width`. 안의 글은 Pretendard 16~24px 또는 `.wm`(워드마크).
- **태그 `.tag`**: 30px 높이 캡슐 라벨(목차 번호, 기간, 상태). `.tag.o`는 1.5px 아웃라인. 디스플레이 줄 안에 넣지 않는다(그건 `.pl`).
- **캡슐 막대 `.bar`**: 데이터 막대. 높이는 옆 숫자의 캡하이트(96px 숫자 → 56px, 64px → 40px), 폭은 %로. 차트 라이브러리 없이 막대 + 큰 숫자로 끝낸다.
- **기하 도형 `.sh`**: `.c` 원, `.hu` 반원, `.q` 사분원, `.tri` 삼각형, `.cap2` 가로 캡슐. 단계·서비스의 번호 대신 쓴다. 아이콘 세트는 없다 — 도형이 아이콘 역할을 한다.
- **패턴**: 노랑 배경 + 빨강 사분원·삼각형·반원, 180px 격자, 4분할 빨강 띠(18px). 템플릿 `04 Pattern Opener`의 `<svg class="pat">`를 그대로 복제하고 `<path>` 위치만 바꾼다. 좌상단 2×2칸은 제목 자리로 비운다. 노랑/빨강 조합을 뒤집어도 된다(빨강 배경 + 노랑 도형).
- **거대 따옴표 `.qm`**: 사선 꼬리 + 원 2개로 만든 SVG(템플릿 `07 Quote`). 화면 왼쪽 절반을 차지하고 위·아래로 잘리게 둔다. 인용문은 오른쪽에 세리프, 끝에만 닫는 따옴표(”)를 붙인다.
- **행 `.rows`**: 목차·서비스 리스트. 1.5px currentColor 가로선만. 세로선·격자 없음.
- **푸터 `.ft`**: `grid 26% 22% 1fr auto`. 설명(2줄) · `Page NN` · `Copyright 2026` · `.wm`. 원색 배경에서는 글자색을 따라간다(노랑+빨강 패턴 장은 빨강).

## 5. 아키타입 (템플릿에 전부 있음)

**덱 `templates/deck.html`**
1. **Cover**(흰): 디스플레이 3줄 244px, 캡슐 4색(연도·워드마크 캡슐 포함).
2. **Statement**(노랑): 한글 Jua 양끝 맞춤 6줄, 92px. 영문이면 Righteous 대문자 64~72px로 같은 방식.
3. **Index**(흰): `INDEX` + 검정 캡슐 한 줄, 아래 색 태그 번호 목차 4행.
4. **Pattern Opener**(노랑+빨강): 패턴 풀블리드 + 좌상단 빨강 디스플레이 2줄 + 한글 부제. 챕터 구분장 겸용.
5. **Process**(흰): 좌상단 디스플레이 2줄 + 우측 서브, 아래 4열(도형 · Step 라벨 · Jua 제목 · 캡션 2줄).
6. **Numbers**(코발트): 디스플레이 제목, 숫자 · 캡슐 막대 · 라벨 3행(노랑·빨강·흰 막대).
7. **Quote**(흰): 왼쪽 거대 따옴표, 오른쪽 세리프 인용 + 출처.
8. **Closing**(그린): `THANK / YOU!` + 캡슐, 아래 연락처 3열(Mail · Call · Next).

**문서 `templates/doc.html`**: Hero(흰, 디스플레이 3줄) → Statement(노랑) → Services(흰, 도형 리스트) → Pattern(노랑+빨강 띠, 360px) → Numbers(코발트) → Quote(흰) → Contact(그린). 블록은 radius 14, 간격 14px, 바깥은 `--mist`.

## 6. 레이아웃 규칙

- **덱 좌표계**: 좌우 40px, 상단 36~44px, 푸터 bottom 24px. 콘텐츠는 y 640을 넘기지 않는다(푸터 자리).
- **크게 → 작게, 중간 없음.** 화면에는 거대한 것(디스플레이·숫자·따옴표·패턴)과 아주 작은 것(푸터·캡션·라벨)만 있다. 20~40px 중간 크기 요소를 여러 개 늘어놓지 않는다.
- **제목 줄**: 좌측 디스플레이, 우측 `.sub`(폭 320~380px)를 `align-items:flex-end`로 바닥 맞춤.
- **블리드**: 패턴·따옴표·통짜 배경은 화면 끝까지. 디스플레이 글자는 좌우 40px 여백 안에서 꽉.
- **줄바꿈은 직접**: 디스플레이·Statement는 줄을 직접 나눈다(`.ln`, `<div>`). 본문은 `<br>`로 의미 단위에서 끊는다.

## 7. 카피 규칙

- 영문 디스플레이는 짧고 장난스럽게: `HELLO?`, `NEW PROJECT`, `HOW WE WORK`, `NUMBERS`, `THANK YOU!`. 물음표·느낌표 허용.
- 한글 Statement는 "우리는 ~합니다" 형태의 선언 한 덩어리, 4~6줄.
- 본문·캡션은 한글, 두 줄 안에서 끝낸다. 숫자를 앞에 세운다("15초 · 30초 컷", "주 1회 시사").
- 근거 없는 최상급("국내 최고", "유일")은 쓰지 않는다. 브랜드명·로고는 의뢰처 것만, 없으면 `BRAND`.

## 8. 금지 사항

- 그라데이션, 그림자(`box-shadow`), 글로우, 3D, 스톡 사진, 이모지, 컬러 아이콘
- 4원색 외 색, 파스텔 틴트, 반투명 색 겹침
- 둥근 카드 박스로 내용 감싸기, 카드 균등 나열
- 디스플레이 글자를 가운데에 작게, 또는 좌우 여백이 크게 남게 두기
- 캡슐이 글자보다 낮거나 기준선이 어긋난 상태, 디스플레이 줄 안의 작은 태그
- Righteous에 한글 넣기, 한글에 bold·이탤릭·자간 확장
- 가운데 정렬 본문 단락, 불릿 5개 이상

## 9. 검수 체크리스트 (렌더 PNG를 보면서)

- [ ] 디스플레이 줄이 좌우 40px 여백까지 꽉 차고, 오른쪽이 잘리거나 넘치지 않는다.
- [ ] 캡슐 위·아래 끝이 글자 위·아래 끝과 일치한다.
- [ ] 디스플레이·물음표 점 등이 푸터와 겹치지 않는다(콘텐츠 y ≤ 640).
- [ ] Statement 각 줄이 양끝에 닿고, 어절 중간에서 끊기지 않는다.
- [ ] 한 장 배경 1색, 같은 배경 2장 연속 없음, 원색 4개 외 색 없음.
- [ ] 모든 장에 푸터가 있고 Page 번호가 실제 순서와 맞다.
- [ ] Righteous · Jua · 세리프가 로드됐다(대체 고딕으로 보이면 링크·네트워크 확인).
- [ ] 패턴 도형이 제목·부제를 덮지 않는다.
